# Reglas y Habilidades del Proyecto (Project Skills & Rules)

Durante el desarrollo de este proyecto, el asistente debe adoptar las siguientes habilidades, enfoques y pautas de comportamiento:

## 1. Diseño y UI (Frontend)
- **Emil Kowalski**: Priorizar animaciones fluidas, naturales y de alta calidad para las interfaces de usuario.
- **Impeccable Design**: Mantener un diseño impecable con un enfoque meticuloso en la tipografía, el espaciado (whitespace) y la estructura del layout.
- **Taste Skill**: Basar las decisiones de interfaz en referencias reales de diseño para lograr interfaces modernas y visualmente atractivas.
- **Improving Frontend Design**: Buscar proactivamente formas de mejorar el diseño del frontend en cada iteración.
- **Glassmorphism & Liquid UI / Estilo Dark**: Para TODO el frontend, usar una interfaz estilizada basada en Glassmorphism (efecto cristal esmerilado, fondos translúcidos con `backdrop-filter: blur`, bordes sutiles, sombras suaves) combinada con la "Liquid Navigation" (estilo dark, esquinas redondeadas, contrastes limpios). Todo el diseño, absolutamente todo, debe seguir este principio visual.
- **Cero Emojis & Bootstrap Icons**: ESTÁ PROHIBIDO EL USO DE EMOJIS en el frontend. Usar absoluta y únicamente íconos de Bootstrap (`bootstrap-icons`) para cualquier representación gráfica.

## 2. Pruebas y Calidad
- **Playwright**: Utilizar Playwright para la creación y ejecución de pruebas (testing).
- **Napkin (Memoria de Errores)**: Mantener un registro y memoria de los errores encontrados para no repetirlos y aprender de ellos.

## 3. Comunicación y Estilo
- **Caveman**: Usar frases cortas, directas y al grano cuando sea apropiado.
- **Humanizer**: Redactar con un tono natural y humano para mejorar la legibilidad y comprensión.
- **Token Optimizer**: Mantener las respuestas eficientes en cuanto a longitud y uso de tokens (ser conciso pero efectivo).

## 4. Herramientas del Agente
- **Find-Skill**: Capacidad para buscar y aplicar la habilidad específica que se necesite en un momento dado.
